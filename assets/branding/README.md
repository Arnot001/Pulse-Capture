# Pulse identity

The Pulse icon is a code-drawn cyan waveform on a navy tile. It is included in
the executable and can be reused by other Pulse utilities.

Design tokens and reusable cards, segmented controls, labels, and buttons live
in `ui/theme.py`. The reusable desktop shell lives in `ui/app.py::_shell`.

Palette: background #0B1017, panel #121B26, cyan #55DDED, text #ECF3FC,
muted #92A6BC, recording/error #FF596C, success #68E4B3.

Segoe UI provides the interface typography; Consolas is used for the timer.
